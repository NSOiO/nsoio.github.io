Chat Tidy — Privacy Policy

Effective date: May 20, 2026

Overview

Chat Tidy is a Chrome extension that helps you batch-delete and archive ChatGPT conversations. It is designed with a strict privacy-first approach: we do not collect, store, or transmit any user data.

Data Collection

Chat Tidy does not collect any of the following:

  • Personally identifiable information
  • Conversation content or chat history
  • Browsing or web history
  • Authentication credentials
  • Usage analytics or telemetry
  • Location data

Local Storage

Chat Tidy uses chrome.storage.local solely to persist UI preferences such as theme and language. This data never leaves your browser.

Network Requests

Chat Tidy makes zero network requests to any server owned or operated by Chat Tidy. The only network activity is between your browser and ChatGPT's own servers when you perform delete or archive actions — exactly the same requests your browser would make if you deleted conversations manually.

Permissions

  • Host permissions (chatgpt.com, chat.openai.com) — Required to inject the sidebar toolbar into the ChatGPT page.
  • Storage — Required to save UI preferences locally.

Third Parties

Chat Tidy does not share data with any third party because it does not collect any data.

Changes

If this policy changes, the updated version will be posted at this URL with a new effective date.

Contact

For questions about this policy, please reach out via the Chrome Web Store listing support section.
